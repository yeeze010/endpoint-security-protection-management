# 计算机终端安全防护管理系统测试计划

## 1. 测试目标

验证平台在当前演示阶段的前后端主链路、构建脚本、文档交付物和部署材料具备可演示、可验收、可继续迭代的基础质量。

## 2. 测试范围

1. 后端 Spring Boot 项目编译与测试。
2. 前端 Vue 项目类型检查与构建。
3. 本地启动脚本冒烟验证。
4. Docker 编排与部署材料检查。
5. 需求、设计、API、测试、部署、验收文档完整性检查。

## 3. 测试策略

### 3.1 自动化检查

| 类别 | 命令或方式 | 通过标准 |
|---|---|---|
| 后端测试 | `mvn test` | 用例通过，进程退出码为 0 |
| 前端类型检查与构建 | `npm run build` | 类型检查通过且打包成功 |
| 交付物校验 | GitHub Actions `deliverables` 任务 | 核心文档与图示存在 |

### 3.2 手工冒烟

| 场景 | 步骤 | 预期 |
|---|---|---|
| 首页访问 | 打开 `/dashboard` | 页面可渲染指标、趋势、风险分布 |
| 终端列表 | 打开 `/endpoints` | 列表显示终端数据，可关键词筛选 |
| 终端详情 | 调用 `/api/endpoints/{id}` | 返回对应终端详情 |
| 策略列表 | 打开 `/policies` | 列表可展示策略状态与版本 |
| 告警列表 | 打开 `/alerts` | 告警列表正常显示 |
| 审计日志 | 打开 `/audit` | 可查看审计流水 |

## 4. 测试环境

### 4.1 本地环境

- Windows PowerShell
- JDK 21
- Node.js 22
- npm
- Maven 3.9.x

### 4.2 Docker 环境

- Docker Desktop 或兼容环境
- 可用端口：`80`、`5432`、`6379`、`8080`、`9000`、`9001`

## 5. 测试用例清单

### 5.1 功能用例

1. 登录接口返回访问令牌和权限列表。
2. 仪表盘接口返回指标卡、趋势数据和风险分布。
3. 终端列表支持空关键词与关键词筛选。
4. 不存在的终端 ID 返回失败响应。
5. 策略、告警、审计接口返回结构化列表数据。

### 5.2 非功能用例

1. 前后端构建命令可重复执行。
2. 本地启动脚本在依赖满足时可自动完成基本验证。
3. 关键文档齐备并可供验收引用。

## 6. 缺陷分级

| 级别 | 定义 | 示例 |
|---|---|---|
| P0 | 阻塞验收或无法启动 | 后端无法启动、首页不可访问 |
| P1 | 关键业务链路错误 | 终端列表返回空结构、接口报错 |
| P2 | 次要功能或显示问题 | 文案、布局、筛选异常 |
| P3 | 优化项 | 交互体验、提示信息优化 |

## 7. 退出准则

1. 后端测试通过。
2. 前端构建通过。
3. 演示版五个页面和对应接口可访问。
4. 交付文档、设计图、部署材料完整。
5. 已知风险在验收说明中记录。
