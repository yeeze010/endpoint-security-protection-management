# 测试计划

## 1. 测试目标

按照 `gstack` 的工程闭环原则，测试必须覆盖“能启动、能访问、能完成核心流程、能验收”。测试对象包括前端页面、后端接口、Agent 通信协议、策略下发、告警闭环、文件上传、权限审计和部署脚本。

## 2. 测试分层

| 层级 | 范围 | 工具建议 | 质量门禁 |
|---|---|---|---|
| 单元测试 | 风险评分、策略冲突、权限判断、状态机 | JUnit、Vitest | 核心规则覆盖率不低于 70% |
| 接口测试 | REST API、Agent 上报、文件接口 | Postman/Newman、JUnit | 核心接口 100% 有用例 |
| 前端测试 | 表单、列表、空态、错误态、权限菜单 | Vitest、Playwright | 核心页面无控制台错误 |
| 集成测试 | 策略发布、任务执行、告警派单 | Testcontainers | 主流程通过 |
| 性能测试 | 心跳、事件上报、查询、导出 | JMeter、k6 | P95 小于验收阈值 |
| 安全测试 | 鉴权、越权、注入、文件上传 | OWASP ZAP、依赖扫描 | 高危为 0 |
| 验收测试 | 角色端到端操作 | 手工 + 截图归档 | 用例签字通过 |

## 4. 性能验收指标

| 场景 | 指标 |
|---|---|
| 终端规模 | 支持 10,000 台终端基础接入 |
| 心跳吞吐 | 每分钟 10,000 条心跳无堆积 |
| 事件上报 | 每分钟 50,000 条安全事件可异步消费 |
| 告警查询 | 常用筛选 P95 小于 1 秒 |
| 终端列表 | 10 万资产分页查询 P95 小于 1.5 秒 |
| 报表导出 | 月度报表 5 分钟内生成 |

## 5. 安全测试重点

- 未登录访问 API。
- 低权限用户访问高权限资源。
- 跨组织数据越权。
- 策略发布接口重放。
- Agent 伪造注册、伪造心跳、伪造事件。
- 文件上传扩展名绕过和 MIME 绕过。
- SQL 注入、XSS、日志敏感信息泄露。
- 预签名 URL 超期访问。

## 6. 缺陷分级

| 等级 | 定义 | 修复要求 |
|---|---|---|
| P0 | 系统不可启动、数据泄露、权限绕过、核心流程中断 | 立即修复 |
| P1 | 核心功能不可用、错误数据、严重性能问题 | 当迭代修复 |
| P2 | 一般功能缺陷、体验明显问题 | 进入缺陷池排期 |
| P3 | 文案、样式、小范围优化 | 可延后 |
