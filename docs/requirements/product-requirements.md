# 需求规格说明

## 1. 项目定位

计算机终端安全防护管理系统面向企事业单位、政企园区、多分支机构和内网办公场景，建设统一的终端安全运营平台。系统通过终端 Agent、管理后台、策略中心、告警处置中心和报表审计能力，实现终端资产可视、风险可量化、策略可下发、告警可闭环、过程可审计、结果可验收。

平台第一阶段定位为“企业终端安全运营后台 + Agent 接入服务”的工程骨架，后续逐步接入真实病毒防护、补丁扫描、外设控制、软件白名单和文件隔离能力。

## 2. 用户角色

| 角色 | 职责 | 关键权限 |
|---|---|---|
| 超级管理员 | 系统初始化、租户、组织、角色、全局配置 | 全部配置、全部数据、审计查看 |
| 安全管理员 | 策略配置、告警研判、风险治理、报表输出 | 策略、告警、风险、报表 |
| 运维管理员 | Agent 部署、终端资产、补丁任务、任务重试 | 终端、Agent、补丁、任务 |
| 审计员 | 查看操作日志、策略变更、处置记录 | 只读审计、只读报表 |
| 部门负责人 | 查看本部门终端风险与整改进度 | 本部门数据只读、整改确认 |
| 终端用户 | 接收本机安全提醒、补丁重启提示、外设申请结果 | 本机通知、申请记录 |

## 3. 核心业务流程

### 3.1 终端接入流程

1. 管理员生成 Agent 安装包或部署令牌。
2. 终端安装 Agent，采集主机名、IP、MAC、系统版本、Agent 版本。
3. Agent 调用注册接口，管理端生成 `agent_id` 与终端资产记录。
4. Agent 周期性心跳，上报在线状态、病毒防护状态、补丁状态和策略版本。
5. 管理端根据组织、标签、动态分组计算终端应执行策略。

### 3.2 策略下发流程

1. 安全管理员创建策略草稿。
2. 系统执行规则校验和冲突检测。
3. 高风险策略进入审批。
4. 策略按组织、标签、终端动态组灰度发布。
5. Agent 拉取策略版本并执行。
6. 执行结果回传，失败进入任务重试或人工处理。
7. 策略异常可回滚到上一稳定版本。

### 3.3 告警闭环流程

1. Agent 或后端规则产生告警。
2. 告警聚合去重，按严重级别、终端风险和影响范围排序。
3. 安全管理员研判后派单给责任人。
4. 处置动作包括隔离文件、终止进程、补丁修复、外设阻断、白名单调整。
5. 责任人提交处置结论。
6. 安全管理员复核并关闭。
7. 系统归档证据、审计日志和报表指标。

## 4. 功能模块

| 模块 | 子功能 | 说明 |
|---|---|---|
| 统一门户与权限 | 登录、MFA、RBAC、数据权限、菜单权限 | 支撑多角色后台访问 |
| 终端资产 | 资产台账、分组标签、软硬件清单、在线状态 | 建立终端安全底座 |
| Agent 管理 | 注册、心跳、升级、策略拉取、事件上报 | 管理端与终端之间的执行通道 |
| 安全策略 | 防病毒、外设、白名单、补丁、隔离、基线策略 | 支持草稿、审批、发布、回滚 |
| 补丁/病毒状态 | 补丁缺失、病毒库版本、防护开关、扫描状态 | 形成终端合规判断 |
| 外设管控 | USB、蓝牙、打印、移动存储、白名单 | 防止数据外泄和违规接入 |
| 软件白名单 | 应用清单、允许/禁止规则、例外申请 | 控制高风险软件运行 |
| 风险评分 | 评分模型、风险等级、趋势、整改建议 | 驱动优先级治理 |
| 告警中心 | 告警聚合、研判、派单、处置、复核 | 闭环安全运营 |
| 文件附件 | 证据上传、隔离文件、报表导出、补丁包 | 统一接入 MinIO |
| 报表审计 | 资产报表、风险报表、合规报表、操作审计 | 支撑管理汇报和验收 |

## 8. 告警通知规则

| 场景 | 等级 | 通知对象 | 通知方式 | 升级规则 |
|---|---|---|---|---|
| 恶意文件检出 | 严重 | 安全管理员、终端负责人 | 站内信、邮件、Webhook | 30 分钟未处理升级给负责人 |
| Agent 离线超阈值 | 中 | 运维管理员 | 站内信、邮件 | 2 小时未恢复升级 |
| 高危补丁缺失超 7 天 | 高 | 运维管理员、部门负责人 | 站内信、周报 | 超 14 天进入风险通报 |
| 外设违规接入 | 中 | 安全管理员、部门负责人 | 站内信 | 重复 3 次升级 |
| 防护关闭 | 高 | 安全管理员、运维管理员 | 邮件、Webhook | 15 分钟未恢复升级 |
| 策略执行失败 | 中 | 策略创建人、运维管理员 | 站内信 | 连续 3 次失败转工单 |

## 9. 文件附件管理

| 类型 | 存储位置 | 保留策略 | 访问控制 |
|---|---|---|---|
| 告警证据文件 | MinIO `alert-evidence` 桶 | 180 天，可归档 | 告警相关人员、审计员 |
| 隔离文件 | MinIO `quarantine` 桶 | 默认 90 天，支持审批恢复 | 安全管理员 |
| 补丁包 | MinIO `patch-package` 桶 | 跟随补丁版本 | 运维管理员 |
| Agent 安装包 | MinIO `agent-release` 桶 | 保留最近 5 个版本 | 运维管理员 |
| 报表导出 | MinIO `report-export` 桶 | 30 天自动清理 | 发起人、审计员 |

文件接口必须使用预签名 URL 或后端代理下载；所有文件读取、恢复、删除、导出动作必须写入审计日志。
