# 终端安全防护管理平台验收标准

## 1. 验收目标

确认平台在当前阶段满足演示交付、研发协同和后续扩展的基础要求，并形成可追溯的验收依据。

## 2. 文档验收项

| 项目 | 标准 |
|---|---|
| README | 描述项目目标、结构、启动方式、版本规划 |
| 需求文档 | 包含功能结构、流程、页面、数据、权限、指标 |
| 设计文档 | 包含架构、模块、部署、权限和风险说明 |
| API 文档 | 列出已实现接口和待补接口 |
| 测试计划 | 包含范围、策略、环境、用例和退出准则 |
| 部署方案 | 包含本地、Docker、CI/CD、回滚 |
| Git/GitHub 规范 | 包含分支、提交、PR 和版本策略 |

## 3. 功能验收项

| 模块 | 验收标准 |
|---|---|
| 登录接口 | 返回令牌、用户名、角色和权限列表 |
| 安全态势 | 首页可显示指标、趋势和风险分布 |
| 终端资产 | 列表与详情接口可返回演示数据 |
| 策略中心 | 列表页与接口可用 |
| 告警处置 | 列表页与接口可用 |
| 审计日志 | 列表页与接口可用 |

## 4. 工程规范验收项

| 项目 | 标准 |
|---|---|
| Issue 模板 | 缺陷与需求模板齐备 |
| PR 模板 | 含变更摘要、验证说明、风险说明 |
| CI 工作流 | 后端、前端、交付物检查可运行 |
| 分支规范 | README 与 Git 规范文档一致 |

## 5. 测试验收项

1. `backend` 执行 `mvn test` 成功。
2. `frontend` 执行 `npm run build` 成功。
3. 本地脚本在依赖满足时可完成基本健康检查。
4. 已知风险已记录，不影响当前演示版验收结论。

## 6. 不通过条件

1. 核心页面无法访问。
2. 后端接口无法启动或返回结构错误。
3. 基础文档缺失严重，无法支持研发与验收。
4. CI 基础检查无法通过。

## 7. 当前已知风险

1. 认证授权仍为开发占位实现。
2. 后端接口尚未接入真实数据库。
3. 前端缺少自动化 UI 测试。

## 8. 下一阶段验收前置项

1. 接入 PostgreSQL 持久化。
2. 完成角色权限拦截。
3. 补齐策略发布与告警工单动作。
4. 增加自动化测试覆盖率。
